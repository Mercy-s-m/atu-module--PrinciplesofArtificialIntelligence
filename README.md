In my GitHub repository, I showcase a project from my Principles of Artificial Intelligence module, where I tackled two key AI problems. 
The first involved creating a knowledge base using Prolog to define relationships among various animal species, while the second focused on building Bayesian Network 
and Neural Network models using a mental health dataset from Kaggle.

This hands-on project allowed me to apply AI principles to solve real-world problems, using tools like Prolog for logic programming and Scikit-learn for machine learning models. 
The project contributed significantly to my understanding of AI techniques, data preprocessing, and model evaluation​.
